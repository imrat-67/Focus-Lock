# Focus Lock

Free Android app that helps students focus by locking their phone (whole phone or chosen apps), now or on a schedule — by themselves or remotely by one consenting Observer (parent/friend). Emergency 6-digit password or Observer remote-unlock ends a lock.

- Spec: [SRS.md](SRS.md) · Design: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- AI-assisted development: start at [Cloud_Memory/START_HERE.md](Cloud_Memory/START_HERE.md)
- Stack: Kotlin, Jetpack Compose, Firebase (Spark/free). Android 8.0+. Distributed as an APK.

Status: early development — see Cloud_Memory/STATUS.md.
